Drop your music here: .mp3, .ogg or .wav files. (This is the folder the game reads - not a "music/" folder at the repo root.)

Every file in this folder plays in name order, then starts over. One file just loops.
Name them 01_..., 02_... to choose the order. An empty folder (like this one) means no music.

In a match: M mutes, and - / + lower and raise the volume (shown by the meter in the bottom-right of the HUD).
